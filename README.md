## 시세 수정 방법

`index.html` 아래쪽의 `RATES` 부분만 고치면 됩니다.

```js
const RATES = {
  updated: "2026.08.26",        // 갱신 날짜

  hero: {                       // 메인 화면 시세 (1돈 기준)
    gold: 770000,               // 순금 24K
    k18:  570000,
    k14:  442000,
    pt:   180000,               // 백금
    ag:  3050000                // 은 1kg
  },

  live: [ ... ],                // 실시간 금시세 표 (살 때 / 팔 때 / 전일대비)
  buy:  [ ... ]                 // 제품별 매입시세
};
```

- `sell` 이 `null` 이면 "제품시세적용" 으로 표시됩니다
- `sellD` / `buyD` 는 전일 대비 (+오름 / −내림 / 0 변동없음)
